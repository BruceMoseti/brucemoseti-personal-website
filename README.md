## Tech stack

- React 19 + Vite
- Framer Motion + Lenis
- GitHub Pages deploy (`gh-pages` branch)

## Run locally

```bash
npm install
npm run dev
```

Open the local URL Vite prints (base path: `/brucemoseti-personal-website/`).

## Build & deploy

```bash
npm run build
npm run preview   # local production preview
npm run deploy    # publish dist/ to GitHub Pages
```
